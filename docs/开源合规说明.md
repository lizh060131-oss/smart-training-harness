# 智训引擎 · 开源合规说明

## 1. 自研代码

以下文件为本队原创，随作品一并提交，可复现：

- `harness_v2/engine.py` —— 轮次引擎（漂移诊断 / 实验规划 / 门控决策 / 记录 / SwanLab 镜像）
- `harness_v2/main.py` —— 统一 CLI 入口
- `harness_v2/pytrio_tools.py` 和 `harness_v2/bearing_gate.py` —— 受限策略工具与轴承等权门控
- `harness_v2/configs/{A,B,C}.json` —— 三任务配置
- `tools/` —— 数据转换与批处理脚本（gas / bearing / cmapss 数据流构建、Docker 辅助）

## 2. 官方基线代码

`harness_v2/baselines/{model,data,train,predict}.py` 来自主办方提供的
「代训模型」基线包（cpu-a-guide / cpu-b-rul / cpu-c-guide，20261110-v1），
按赛事规则作为续训基线与预测协议使用。`train.py`、`data.py` 增加按轮复用的特征数组和
评估输入，复用前核对 JSONL 的 SHA-256 及特征路径。另保留两处文件权限兼容调整：

1. 训练暂存目录 `staging.mkdir(mode=0o700)` → `mode=0o755`；
2. `tempfile.TemporaryDirectory` → `tempfile.mkdtemp(...)` + `try/finally shutil.rmtree`，
   使 Python 3.12 在受限目录权限下也能正常清理临时目录。

工业模型结构、标准化、优化器状态、检查点格式和预测入口沿用官方实现。

## 4. 数据合规

- 任务 A 气体数据、任务 B 轴承数据、任务 C 发动机数据均来自主办方「比赛数据」目录，
  仅用于本次赛事评测；

- 训练/验证/回放切片严格隔离，验证集与回放池不参与训练，符合赛事"只用平台允许数据"要求。
